# 팀 검증 및 AI 사용 기록

## 원칙

AI는 미션 명세와 저장소 기록을 비교하고 문서 구조, 링크, 테스트와 누락 목록을 정리했습니다. 팀원의 과거 의도, 실제로 실행하지 않은 Git 명령, 개인 계정의 review·reply·approve를 대신했다고 주장하지 않습니다.

최종 통합자는 타인의 branch를 임의로 고쳐서 결과를 확정하지 않습니다. 각 작성자가 자기 변경을 확인하고, 다른 팀원이 리뷰한 뒤 보호된 `main`에 PR로 병합합니다.

## 에이전트가 한 일

- 명세의 중복 문장을 원자 요구사항으로 정리하고 저장소·Git 객체·GitHub PR 타임라인과 대조
- README, CONTRIBUTING, SUBMISSION, 감사 보고서와 검증용 unittest 초안 작성
- `git show --remerge-diff`로 확인한 우발 충돌 3건을 “히스토리 기반 재구성”으로 기록
- 사람만 할 수 있는 GitHub 계정 행동과 실제 충돌/revert 실습을 별도로 분리

## 에이전트가 하지 않은 일

- 다른 팀원의 branch에 commit을 대신 작성하거나 push하지 않음
- 우발 충돌을 의도적 실습으로 소급 변경하지 않음
- 아직 실행하지 않은 두 충돌의 hash·marker·결과를 만들어 쓰지 않음
- 팀원 명의의 review, reply, approve 또는 최종 팀 합의를 대행하지 않음

## Discord에 전달할 메시지

아래 내용을 팀 채널에 전달하고 다섯 명이 링크를 읽은 뒤 오류가 있으면 수정 의견을 남깁니다.

```text
[Git 협업 미션 최종 검증 요청]

AI를 사용해 정답을 대신 제출한 것이 아니라, 원 명세와 현재 Git/GitHub 기록을 대조해 누락과 사실관계를 정리했습니다.

1. 정합성 보고서: docs/mission-audit.md
2. 기존 PR 13건과 Draft #31의 실제 증빙: docs/pr-evidence.md
3. 실제 남은 행동과 담당: docs/human-actions.md
4. 우발/의도적 충돌 구분: docs/conflict-resolution.md
5. 제출 링크 인덱스: SUBMISSION.md

중요: 기존 충돌 3건은 실제였지만 의도적 실습으로 세지 않습니다. 다음 모임에서 팀원 5명 중 실제 참여자 2명을 정해 같은 한 줄을 다르게 수정하는 충돌 2회를 실행하고, 두 사람의 실명·계정·commit hash·marker를 남깁니다. PR #31의 빨간 한 줄은 공개된 리뷰 실습용 고의 오류이므로, 최건영의 실제 줄 단위 지적 뒤 이준혁이 수정 commit과 답글을 남기기 전에는 정답이나 완료로 세지 않습니다. 그 밖에는 열린 PR 4건 정리, #28/#29 병합 중 생기는 기존 우발 충돌 해결, 병합된 PR의 짧은 사후 사실 보완, revert 실습과 최종 승인이 남아 있습니다. 세부 담당은 human-actions.md 한 곳만 기준으로 봅니다.

각자 본인 이름, 역할, PR/review 기록이 사실과 맞는지 확인하고 이 채널에 `확인` 또는 정정 내용을 답해주세요. 실행하지 않은 작업은 완료로 표시하지 않습니다.
```

Discord의 확인은 팀 합의와 책임 범위를 투명하게 남기는 보조 증빙입니다. 명세가 요구하는 GitHub PR review·reply와 Git commit 기록을 대체하지는 않습니다.

## 최종 통합자 보호 장치

1. `main` 직접 push 없이 모든 변경을 PR로 병합합니다.
2. 김강현은 정리 PR에서 #26 revert를 실제 수행하고, 작성자가 아닌 최건영이 독립적으로 리뷰·승인·병합합니다.
3. 각 기록은 `확인됨`, `히스토리 기반 재구성`, `PENDING`을 구분합니다.
4. 팀원의 branch는 해당 팀원이 확인·push하며, 통합자는 사전 합의 없이 덮어쓰지 않습니다.
5. 최종 제출 직전 다섯 명의 Discord 확인, GitHub 링크, 테스트 결과와 Git graph를 함께 보존합니다. 이는 명세의 별도 점수 항목이 아니라 최종 통합자에게 책임이 몰리지 않게 하는 팀 합의 증빙입니다.

## 학습 정리

이준혁은 팀이 수행한 실제 충돌 2회의 기록을 검토하고 최종 통합을 마친 뒤, 자신이 이해한 브랜치 포인터, PR/리뷰의 가치, 충돌 마커, reset/revert/stash 차이를 별도 학습 노트로 정리합니다. 선택한 결과물 A의 필수 제출물은 아니지만, AI가 정답을 대신한 것이 아니라 실제 과정을 이해했음을 자기 언어로 남기는 보호 장치입니다. 실행하지 않은 일을 대신 증명하는 문서로 사용하지 않습니다.
